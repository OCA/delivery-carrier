This module adds the option to set the maximum quantity that a carrier
can accept. When the total quantity of a sale reaches the limit, the
carrier is not available for selection.

**Table of contents**

.. contents::
   :local:

Usage
=====

- Go to any delivery carrier and set the ``max_quantity`` field.
- Create a sale order with products that reach the maximum quantity.
- Try to select a carrier; this carrier is not available

Known issues / Roadmap
======================

A sale order can have lines with different units of measure. This module
does not perform any conversion between units of measure.
