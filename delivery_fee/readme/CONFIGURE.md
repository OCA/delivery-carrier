The first thing we need to do is create a delivery fee product:

1. Go to _Sales > Configuration > Shipping Methods_ and choose one.
1. In the **Fee product* field start writing the name of the product that will be use
   to charge the fee and pick _Create and edit_.
1. Set the name of the product, its price and its taxes.
1. Set the **Sales description** if you want to show a message in the pickings and
   invoices footer. (you might need to set **Can be sold** checkbox temporarily to do so)
1. Optionally you can set an image that will be printed along with the text.

If you want to do exemptions for a partner:

1. Go to that partner's form.
1. In the _Sales & Purchase_ tab, _Sales_ section, you'll find the the **Delivery fee
   exemption** checkbox.
