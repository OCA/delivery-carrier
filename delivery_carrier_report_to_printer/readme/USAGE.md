- Go to the delivery method and set the `Label report` field. 
- In the selected report, configure the printer options as needed; to print directly, make sure to set a printer and the action to send to server.
- Create a picking and set this delivery method.
- Validate the picking and send it to the shipper.

When this delivery method is integrated with an external API and an attachment is created, it can be sent directly to the printer according to the report configuration.
