This module allows the user to set a report in the delivery.carrier and
enables them to configure it to print directly. By default, this module
creates a dummy report as a workaround that lets you configure options
related to the printer, but the label must be obtained from the API of
each delivery integration.

Usage
=====

- Go to the delivery method and set the ``Label report`` field.
- In the selected report, configure the printer options as needed; to
  print directly, make sure to set a printer and the action to send to
  server.
- Create a picking and set this delivery method.
- Validate the picking and send it to the shipper.

When this delivery method is integrated with an external API and an
attachment is created, it can be sent directly to the printer according
to the report configuration.

Known issues / Roadmap
======================

This module expects the delivery modules to create an attachment when
the send_shipping method is called. Modules that do not generate the
label in this method are not compatible.
