Delivery Dachser

This module integrates Odoo’s delivery framework (along with delivery_package_number, delivery_state, and stock_picking_volume) with Dachser REST API v2 (https://api-gateway.dachser.com/rest/v2), providing end-to-end European Logistics and Food Logistics automation:

  • Shipment & Picking Submission (``stock.picking``):
    • Automatic or manual submission of transport orders (POST /rest/v2/transportorders/{basket}) in imported, labelled, or sent baskets, plus standalone label generation (POST /rest/v2/labels) with automatic test-environment fallback.
    • Seamless synchronization with delivery_package_number (number_of_packages), delivery_state (delivery_state, tracking_state, tracking_state_history, pod_file), and stock_picking_volume (volume).
    • Automatic assignment of 18-digit GS1 SSCC codes to physical Odoo packages (stock.quant.package).
    • Automatic address splitting (name1/name2, street1/street2, house number extraction) complying with Dachser REST API v2 field length limits.
  • Label Generation (PDF & Thermal ZPL):
    • Instant attachment of PDF or ZPL shipping labels in the picking chatter, supporting standard GS1 EAN 1D barcodes and 2D DataMatrix (DMC) labels.
    • One-click label reprinting (GET /rest/v2/transportorders/{id}/labels) and return label generation (dachser_get_return_label).
  • Live Tracking, Event History & POD:
    • Direct link to Dachser eLogistics ShipmentPointer.
    • Live shipment status (GET /rest/v2/shipmentstatus) and full timeline history (GET /rest/v2/shipmenthistory).
    • Signed Proof of Delivery (POD PDF) download (GET /rest/v2/pods) attached automatically to the picking and stored in delivery_state’s pod_file.
    • Scheduled cron job (ir.cron) running every 2 hours to synchronize tracking states, download PODs, and audit invoiced freight costs.
  • Daily Loading Manifest (Transfer List):
    • Interactive wizard to download the daily Transfer List PDF (GET /rest/v2/transferlists) for the Dachser driver.
  • Hybrid Freight Tariff Engine & Invoice Cost Auditing:
    • Live Quotation API (POST /rest/v2/quotations) + Local Zone/Weight/Pallet Tariff Rules (dachser.tariff.rule) with automatic fallback.
    • Chargeable Weight Calculation comparing Gross Weight vs. Volumetric Weight (m³ × 333 kg/m³) vs. Loading Meters (LDM × 1850 kg/LDM).
    • Internal Cost Tracking on sale.order and stock.picking even when shipping is free for the customer.
    • Actual Invoiced Cost Auditing (GET /rest/v2/freightcosts) comparing estimated vs. invoiced freight costs (dachser_cost_difference).

Installation

It depends on the modules delivery_package_number, delivery_state and stock_picking_volum that can be found on OCA/delivery-carrier.

Configuration

To configure this module:

  1. Go to Inventory > Configuration > Delivery > Shipping Methods (or Sales > Configuration > Shipping Methods).
  2. Open the preconfigured Dachser European Logistics (targoflex) shipping method or create a new one with Provider = Dachser.
  3. In the Dachser Configuration tab:
    • Enter your Dachser API Key (X-API-Key) (or separate Test API Key and Production API Key) obtained from the Dachser API Portal.
    • Set your Dachser Branch ID (forwarder.id) (e.g. 193), Dachser Customer ID (consignor.id), Division (T for European Logistics, F for Food Logistics), Product (Y for targoflex, Z for targospeed, N for classicline, etc.), and Term Code / Frankatur (031 Free Domicile / CPT, 021 EXW, etc.).
    • Select your Label Format (PDF or ZPL) and Packaging Type (EU Europallet, EP Half Pallet, KT Cardboard Box, etc.).
  4. In the Dachser Tariffs & Costs tab:
    • Choose the Tariff Calculation Mode (API Quotation with Local Tariff Table Fallback, Dachser API Only (/rest/v2/quotations), or Local Tariff Table Only (By Zones / Weight / Pallets)).
    • Configure volumetric conversion factors (333 kg/m3, 1850 kg/LDM), fuel surcharge percentage, tail-lift/notice surcharges, and zone/weight/pallet tariff rules.

Usage

Calculating Shipping Rates on Sales Orders

  1. Create or open a Sales Order and click Add shipping.
  2. Select Dachser and click Get rate.
  3. The wizard displays the Internal Estimated Cost, Chargeable Weight, and a detailed Dachser Quotation Breakdown (either from Dachser’s quotations API or from the matching local tariff rule).
  4. Click Add to apply the shipping line and store the internal cost on the order.

Sending Shipments & Printing Labels from Pickings

  1. Validate the outgoing Delivery Order (stock.picking) or click Send to Shipper.
  2. Odoo sends the transport order to Dachser, assigns SSCC codes to the packages, updates delivery_state and tracking_state_history, records the tracking reference and eLogistics ShipmentPointer URL, and attaches the PDF/ZPL label in the chatter.
  3. In the Dachser Logistics tab of the picking, you can:
    • Click Confirm Order to Dachser TMS (when created in imported or labelled state).
    • Click Dachser Label to reprint PDF/ZPL labels.
    • Click Update Dachser Tracking (or use delivery_state’s tracking update) to fetch live status and event history.
    • Click Download POD to attach the signed Proof of Delivery PDF and populate pod_file.
    • Click Fetch Actual Invoiced Costs to compare Dachser’s invoiced freight cost against the estimated cost.
    • Click Check LDR Route to verify the Dachser destination routing code.

Downloading the Daily Loading Manifest (Transfer List)

  1. Open the Dachser shipping method and click the Manifest / Transfer List smart button.
  2. Select the Order Date (and optional Order Group) and click Query and Download PDF Manifest.
