`DPD Portugal <https://www.dpd.pt>`__ is a leading parcel delivery
service in Portugal, offering express, standard, and economy delivery
services with comprehensive tracking and customer notification features.

This module integrates DPD Portugal shipping services with Odoo. It
allows you to send shipments, generate shipping labels, and follow
parcels on the DPD tracking portal directly from delivery orders.

It leverages the DPD Portugal REST API to register shipments and
download shipping labels automatically upon delivery order validation.
The agreed transport price configured on the carrier is used for
shipping costs, as the DPD API does not provide rating. Cash on delivery
and DPD Predict delivery are supported.

When the OCA ``partner_mobile`` module is installed, its mobile phone
field is used for the DPD mobile contact data. Without it, the regular
partner phone field is used as a fallback.

Configuration
=============

1. Go to **Inventory > Configuration > Carrier Accounts** and create a
   new account with:

   - **Delivery Type**: DPD Portugal
   - **Account Number**: DPD API username
   - **Account Password**: DPD API password
   - **DPD OAuth Client ID** and **DPD OAuth Client Secret**:
     credentials of the OAuth application provided by DPD

2. Go to **Inventory > Configuration > Delivery Methods** and create a
   new carrier with **Provider** set to *DPD Portugal*.

3. In the carrier form, select the **Account** created in step 1, then
   open the **DPD Portugal Configuration** tab and set:

   - **DPD Sub-Account**: the 8-digit DPD sub-account used to register
     shipments
   - **DPD Sender Contact**: the contact person printed on labels
     (defaults to the company partner)
   - **DPD Agreed Price**: price agreed with DPD, used for shipping
     costs (the DPD API does not provide rating)
   - **DPD Label Format**: A4 one label, A4 two labels, or thermal 10 x
     15 cm ZPL
   - **DPD Predict Delivery**: request DPD Predict notifications
   - **Hide Recipient Phone/Email on Label**: omit contact data from
     labels

4. Click the **Test Environment** smart button at the top of the form to
   toggle to **Production Environment** when ready for live shipments.
   The production endpoint is inferred from DPD examples; confirm the
   production URL and credentials with DPD before using it.

Usage
=====

1. Create a sales order and select the DPD Portugal delivery method.
2. Optionally set a **COD Amount** on the picking to ship with cash on
   delivery (amount must be in euros).
3. Confirm the sales order and validate the delivery order.
4. Click **Send to Shipper** to:

   - Register the shipment on the DPD Portugal API
   - Download and attach the shipping label
   - Set the guide number(s) as the tracking reference

5. In production, use the tracking link on the delivery order to follow
   the parcel on the DPD tracking portal. The DPD API does not provide
   shipment status updates, so the tracking state is not updated
   automatically.

Labels are attached to the delivery order as soon as the shipment is
registered.
