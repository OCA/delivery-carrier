Adds a *ZPL Labels* smart button on transfers that have at least one ``.zpl``
attachment (shipping labels generated through ``delivery_roulier``).

The button opens a wizard listing the ZPL attachments of the transfer; selecting
one displays its rendering as a PNG image, generated by the Labelary API
(https://labelary.com/service.html).

The label size is read from the ``^PW`` and ``^LL`` commands of the ZPL file,
and falls back to the configured default size otherwise.
