To use this module no additional configuration is required.

When processing a picking:
- The system automatically calculates the planned dates of all picking steps (Pick / Pack / Delivery) based on the configured warehouse route and delays.
- The final delivery date is validated against the partner’s defined Delivery Schedule.
- If the planned delivery date does not match the partner’s delivery schedule, a warning message is displayed on the picking.
- If no delivery schedule is defined for the partner, an informational message is shown instead.

The planned step dates and delay information are displayed directly on the picking form view.
