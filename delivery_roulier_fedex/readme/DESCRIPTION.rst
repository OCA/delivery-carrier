Generate FedEx shipping labels through the FedEx REST APIs (Ship API v1,
OAuth 2.0), using the Roulier framework provided by ``delivery_roulier``.

- Label generation for one or several packages in a single FedEx shipment (multi-piece shipment)
- Customs clearance data (commodities, HS code, country of origin) sent automatically outside of the European Union
- Optional FedEx Electronic Trade Documents (commercial invoice generated by FedEx)
- Shipment cancellation through the FedEx API, to avoid being charged for unused labels
- OAuth access token cached per process until its expiry
