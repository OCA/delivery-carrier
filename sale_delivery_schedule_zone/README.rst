This module extends the OCA **partner_delivery_schedule_zone** module to
automatically assign a delivery schedule and departure date to sales
orders based on the partner's delivery zone.

When a sales order is confirmed, the next reachable departure slot is
computed from the partner's or zone's schedules, respecting a
configurable cutoff window to avoid assigning slots that are too close
to the current time.

Usage
=====

To use this module:

1. Configure the delivery zones and their schedules in *Inventory >
   Configuration > Delivery Zones*.
2. Assign a delivery zone to each partner.
3. Go to *Settings > General Settings > Inventory* and set the
   **Departure Cutoff** (in minutes) — orders confirmed within this
   window before a departure are rolled to the next available slot.
4. Confirm a sales order. The **Delivery Schedule** and **Scheduled
   Date** fields are automatically filled with the next reachable
   departure.
