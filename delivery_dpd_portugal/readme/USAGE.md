1.  Create a sales order and select the DPD Portugal delivery method.
2.  Optionally set a COD amount on the picking if COD is enabled.
3.  Confirm the sales order and validate the delivery order.
4.  Click **Send to Shipper** to:
    - Create a shipment on DPD Portugal
    - Retrieve and attach the shipping label
    - Set the tracking number on the delivery order
5.  Use the tracking link to monitor shipment status.
