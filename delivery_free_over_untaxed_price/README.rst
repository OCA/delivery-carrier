This module allows to determine if a shipping is free based on the
untaxed price of the sale order, instead of the taxed price, which is
the default in the system.

.. contents::
   :local:

Configuration
=============

To configure this module, you need to:

1. Go to Inventory > Configuration > Delivery Methods
2. Choose a shipping method
3. Mark the "Free if order amount is above" if it is unmarked
4. Check "Use amount untaxed" if the decision of free shipping has to be
   based on untaxed amount.

Usage
=====

To use this module, you need to:

1. Create a new sale order
2. Click the "Add shipping" button
3. Select a delivery method with the "Use amount untaxed" option
4. The free delivery would be computed using the amount untaxed of the
   sale order
